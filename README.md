# Carte digitale VELF — Burdy Goureige

Carte de visite digitale (vCard) accessible via QR code.

## Contenu

| Fichier | Description |
|---------|-------------|
| `qrcode-velf.png` | QR code violet stylisé à imprimer (Canva, cartes de visite) |
| `carte.html` | Carte digitale (aperçu local) |
| `carte-digitale/index.html` | Version hébergée de la carte |

## Fonctionnement

Le QR code pointe vers la carte digitale en ligne. Au scan :
- Affichage de la carte VELF (logo, coordonnées)
- Bouton **« Ajouter à mes contacts »** qui télécharge la vCard
